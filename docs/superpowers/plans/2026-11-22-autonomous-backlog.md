# Автономная очередь задач (с 2026-11-22, около месяца)

Поручение владельца проекта: брать задачи из плана и делать без согласования. Правила работы:

- Каждая задача идёт в своей ветке `work/<тема>`. В `main` ветка попадает fast-forward только после полной проверки: `cargo +1.95.0 fmt/clippy -D warnings/test`, сквозные тесты `compat/`, кросс-проверка `hermes-cli` под Windows (`zig` как C-компилятор).
- Новое поведение подтверждается записью эталона (`compat/create_*`) или сквозным тестом на настоящем `hermes`; тест проверяется мутацией.
- Релизы и теги не публикуются без явной просьбы. Состояние `main` всегда готово к выпуску.
- Расхождения с эталоном, которые сделаны намеренно, записываются в плане рядом с функцией.
- Журнал ниже обновляется после каждой влитой задачи.
